What AIGuard is

AIGuard is an Execution-Layer Security tool: it secures the layer where an agent's decisions become real actions — process and command execution on your machine. It hooks into your assistant's official PreToolUse mechanism, evaluates every shell command against a policy, and returns one of three actions: allow ask block

It is a guardrail against honest-but-fallible agents — not a sandbox, and not a defense against adversarial ones. See Risk Disclosures before relying on it.

Quick start

pipx install aiguard-gate
aiguard setup
aiguard install kimi     # or: aiguard install claude
